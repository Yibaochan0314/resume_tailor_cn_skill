# 简历定制-skill（中国内资企业）

> 一个面向中国大陆内资企业求职的 AI 简历定制工作流。给它一份岗位 JD + 你的工作经历，产出**可直接投递的 A4 两页 PDF + 浏览器里能直接改的可编辑 HTML + 匹配度分析与打招呼话术**。

---

## 这是什么

不是一套简历模板，而是一份**可被 AI 宿主执行的完整工作流**（`SKILL.md` + 参考资料 + 脚本）。它把「投一个岗位」拆成 6 步固定动作，并把实战踩过的坑固化成硬性规范，让每次产出都稳定达标。

### 它解决什么问题

| 常见痛点 | 这套流程的做法 |
|---|---|
| 简历和 JD 对不上，投了没回音 | 先做 JD 五层解码 + 匹配度打分（0.6 经历重合 + 0.2 关键能力 + 0.2 行业业务匹配），再决定强化什么、弱化什么 |
| AI 写出来的简历全是空话 | 硬性写作规范：每个 bullet 必须含「解决什么问题 → 用什么方法/技能 → 拿到什么数据结果」，禁用「负责 / 配合」这类宽泛动词 |
| 一份简历投所有岗位 | 按 JD 关键能力重新选材、关键词口径对齐；同一能力关键词全简历出现 ≤2 处，避免堆砌 |
| 数字看着合理，一被追问就穿帮 | **数据溯源闸门**：动笔前先建「数据 → 出处」映射表，逐条核对；并列出 3 类实测错配雷区（张冠李戴、凭空编造、把公司级结果写成项目成果） |
| 简历写不满一页，或溢出到第三页 | 自评 / 工作 / 项目三层「总分分」结构 + 每个 bullet 限 1-2 行，把篇幅锁在 A4 两页 |
| 导出 PDF 字体乱码、异体字被 ATS 判废 | 内嵌 Noto Sans SC **双字重**（Regular + Bold），根治 `⻓ / ⾃` 这类异体字提取问题 |

## 能产出什么

跑完一个岗位，你会拿到 4 个文件：

| 文件 | 说明 |
|---|---|
| `<公司>-<岗位>-<姓名>-简历.html` | **可编辑简历**：浏览器打开即可直接改文字、传照片、按 JD 能力高亮、导出 Word / PDF、自动历史留档 |
| `<公司>-<岗位>-<姓名>-简历.pdf` | 可直接投递的 A4 两页 PDF（内嵌字体，打印级） |
| `<公司>-<岗位>-分析与打招呼话术.md` | JD 解码、匹配度、Gap 分析、Tailor 策略、打招呼话术（≤250 字） |
| `经历档案-<姓名>.md` | 你自己的经历库，持续累积、越用越准 |

## 安装

### 前置条件

- 一个支持 skill 的 AI 宿主（如 WorkBuddy）
- 可选：Python 3.9+ 与 Google Chrome —— 仅用于让脚本自动转 PDF；没有也能用 HTML 里的「导出 PDF」按钮手动导出

### 方式一：手动拷贝（推荐）

1. 下载或克隆本仓库
2. 把**整个 `resume_tailor_cn_skill` 文件夹**放进宿主的 skills 目录：

```bash
# macOS / Linux
cp -r resume_tailor_cn_skill ~/.workbuddy/skills/
```

```powershell
# Windows PowerShell
Copy-Item -Recurse resume_tailor_cn_skill "$env:USERPROFILE\.workbuddy\skills\"
```

3. 刷新或重启宿主，之后在对话里说「用简历定制 skill 帮我做简历」即可触发

### 方式二：git clone

在本仓库页面点绿色 **Code** 按钮 → 选 **HTTPS** → 复制地址，然后：

```bash
git clone <上一步复制的仓库地址> ~/.workbuddy/skills/resume_tailor_cn_skill
```

用这种方式装的好处是以后能一条命令更新到最新版：

```bash
cd ~/.workbuddy/skills/resume_tailor_cn_skill && git pull
```

### 用在其他 AI 宿主上

`SKILL.md` 是一份纯 Markdown 工作流文档。把它的内容直接粘进对话作为上下文（或存为项目说明文件），同样能驱动整套流程 —— 只是需要你手动执行 `scripts/` 里的脚本。

## 快速开始

**第 1 步 · 建经历档案（只需一次）**
按 `references/experience-archive.md` 的空模板，填一份自己的经历档案：工作经历、项目、可量化数据、荣誉认证。这份档案是后续所有岗位定制的唯一选材来源。

**第 2 步 · 发 JD**
把岗位 JD 的**截图或文本**发给 AI。注意 Boss 直聘的分享链接抓不到内容（Vue SPA + 异步加载 + 风控），直接给截图最快。

**第 3 步 · 收产出**
AI 会跑完下面 6 步流程，过程中可能问你几个问题（匹配度低于 50% 时会做 5 轮深挖问答），最后交付上面那 4 个文件。

## 工作流 6 步

| 步骤 | 做什么 |
|---|---|
| 1 · 读取与解析素材 | 读经历档案全文、提取 PDF 简历文本、识别 JD 截图 |
| 2 · JD 解码与匹配度评估 | 五层解码（真实需求 / Must Have / Nice to Have / 隐藏信号 / 级别判断）+ 匹配度打分 + Gap 三档 + Tailor 策略 |
| 3 · 定制简历内容 | 按 JD 关键能力拆解，从经历中挑最匹配的经验与数据对应展示 |
| 4 · 生成可编辑 HTML | 单文件 HTML，内联 CSS，A4 打印优化，内置全部编辑功能 |
| 5 · 转 PDF 并验证 | CDP 驱动 headless Chrome 转 A4 PDF，逐项验证页数 / 字体 / 边距 / 异体字 |
| 6 · 交付与留档 | 输出 PDF + HTML + 分析与话术文档，经历档案同步更新 |

打开 `assets/resume-template-cn.html` 就能看到效果，全部功能如下：

| 功能 | 说明 |
|---|---|
| 修改和编辑 | 默认全文可直接编辑（切换按钮只改视觉提示，不会锁住输入） |
| 预览 | 弹窗按 A4 排版预览导出效果 |

## 常见问题

**Q：为什么锁定 A4 两页？**
招聘方筛选简历的耐心有限，两页是信息量与可读性的平衡点。流程通过「自评 / 工作 / 项目」的总分分结构和 bullet 行数限制来控篇幅。

**Q：我没传照片，导出的 PDF 会有占位框吗？**
不会。打印样式里已隐藏未上传照片时的整个照片区域和提示文字。

**Q：导出 PDF 出现 `⻓`、`⾃` 这类奇怪的字？**
那是字体缺失导致的异体字回退。本模板已内嵌 Noto Sans SC 双字重，正常不会出现；若你换成自己的字体，请确保嵌入完整字重的子集。

**Q：历史记录会丢吗？存在哪？**
存在浏览器本地 IndexedDB，不上传任何服务器。有三层保障：HTML 内嵌种子自动补全、一键导出/导入 JSON 备份、修改代码不覆盖已保存数据。清空浏览器数据会丢失，重要节点建议导出备份。

**Q：匹配度很低（<50%）怎么办？**
流程会先对缺失的关键能力做 5 轮问答式深挖，挖你的真实经历、动作和数据；挖不到就只呈现已有匹配案例，不硬凑、不杜撰。

**Q：能用来做英文简历吗？**
工作流的中文写作规范（重复度、总分分、句式多样化）是为中文简历设计的。英文简历可以复用 JD 解码与匹配度评估部分，但排版和措辞建议另做调整。

## 隐私说明

- 简历模板**纯本地运行、零网络请求**：没有 CDN、没有外链图片、没有 `fetch` / `XMLHttpRequest` / `WebSocket` 调用（唯一出现的 `http://` 是 SVG / XHTML 的 XML 命名空间声明，不产生请求）
- 你的简历内容与照片只保存在自己浏览器的本地存储（IndexedDB）里，不会上传到任何服务器
- 本仓库**不含任何真实个人信息**：模板正文全部为 `xxx` / 能力关键词占位符，历史种子为空数组

## 使用建议

- 经历档案**只增不改**：每次有新经历、新项目、新数据，立刻追加进去，历史内容不要删。定制时从完整档案里按匹配度选材，池子越大命中率越高
- 简历里的每个数字都要能溯源到档案中的原文，别让「看起来合理」的数字进最终稿
- 交付前建议做一轮自查：bullet 是否超过 2 行、同一能力关键词是否出现超过 2 次、bullet 开头句式是否有重复
